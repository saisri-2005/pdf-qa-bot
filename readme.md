# PDF Question Answering Bot

A Streamlit web application that allows users to upload a PDF and ask questions from it using semantic search.

## Features
- Upload any text-based PDF
- Ask questions in natural language
- Retrieves relevant document content using vector similarity
- Built using LangChain, FAISS, and Sentence Transformers

## Tech Stack
- Python
- Streamlit
- LangChain
- FAISS
- HuggingFace Sentence Transformers
